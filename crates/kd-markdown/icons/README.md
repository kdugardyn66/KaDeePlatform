# Icons

MdCraft's icon set (original drawings, MIT OR Apache-2.0), generated from MdCraft's `web/assets/icons.js`.
`name.svg` holds the stroke parts and `name.a.svg` the parts MdCraft draws in the accent colour;
`kd_markdown::view::md_icon` draws both. Served to GPUI as `md/<name>.svg` (`src/icons.rs`).
